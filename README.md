# desktop-duckling-v2

I already tried to create my desktop duckling in godot around 1 to 2 years ago - but failed miserably lol.
With the ysws program playground by hackclub (https://playground.hackclub.com/) I got the motivation (and guide) to start over again and hopefully do better this time.

I present: Desktop Duckling
The sprites are created by me and the code was based off the playground desktop pet guide. I wrote most code myself but even tho I hate AI I couldn't get some stuff to work without - I am sorry and ashamed of myself :<

Desktop Duckling is a little duck that runs around on your taskbar and just is a little cutiepie. 
It can walk, jump, quack, get picked up, flutter and also get annoyed!

To download it go to https://gabl18.itch.io/mysterious-package, scroll down to the download button and you get the .exe file!
